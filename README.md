# SuperKids

A top-down adventure game designed by Elin, starring her and her friends, set in Arlington, MA.

**Play:** https://jgoldshlag.github.io/superkids/

## Develop

```
npm install
npm run dev      # http://localhost:5173 (also on your LAN, so you can test on the iPad)
npm run build    # production build into dist/
```

## Deploy

Push to `main`. GitHub Actions builds the game and publishes it to GitHub Pages automatically
(see `.github/workflows/deploy.yml`).

## Controls

- Computer: arrow keys or WASD
- iPad / touch: touch and drag on the left half of the screen
